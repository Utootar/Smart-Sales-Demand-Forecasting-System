# AI Data Analytics Platform ()Demo
An AI-powered analytics platform that automatically transforms raw business data into actionable insights.
Built with:
- Data Engineering
- Automated ETL Pipeline
- Statistical Analysis
- Machine Learning
- Generative AI Reporting
-- Overview
This project simulates a real-world Data Analyst / ML Engineer workflow.
The system automatically:
1. Connects to data sources
2. Profiles dataset quality
3. Performs automated ETL
4. Runs statistical analysis
5. Trains multiple ML models
6. Generates AI executive reports

Supports:
- CSV
- Excel
- MySQL Database

Capabilities:
- Database connection
- Table selection
- Data preview
- Raw data preservation

Automatically detects:
- Data types
- Missing values
- Duplicate records
- Feature candidates
- Target candidates
