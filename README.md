# Smart-Sales-Demand-Forecasting-System
An Inventory &amp; Sales Management system integrated with Statistical Analysis, featuring ABC Classification, Trend Analysis, and Demand Forecasting using Moving Average models.

Methodology
The application follows a standard Data Science pipeline:
Connection: Securely login to MySQL server.
Preprocessing: Handles missing values and removes statistical outliers via IQR.
Feature Engineering: Creates temporal features to capture seasonal trends.
Evaluation: Provides R2 Score, MSE, and MAE metrics for performance assessment.

Prerequisites
* Python 3.9+
* MySQL Server
* Virtual Environment (Recommended)

Key Features
 **Multi-Model Forecasting:** Compare performance across 6 different algorithms:
    * Linear Regression
    * Random Forest Regressor
    * Gradient Boosting
    * K-Neighbors (KNN)
    * Support Vector Regression (SVR)
    * Decision Tree

Tech Stack
 **Language:** Python
 **Frontend:** Streamlit
 **Database:** MySQL (via SQLAlchemy & PyMySQL)
 **ML Libraries:** Scikit-learn, Statsmodels
 **Visualization:** Matplotlib, Pandas
